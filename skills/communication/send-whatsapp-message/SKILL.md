# Send WhatsApp Message Skill

Guides sending messages via WhatsApp Web or desktop client using verified credentials.

## When to Use
- The boss requests sending a WhatsApp message to a specific contact or phone number.

## Procedure
1. Navigate to WhatsApp Web chat endpoint: `https://web.whatsapp.com/send/?phone=<number>&text=<message>`.
2. Wait for WhatsApp interface and message input to focus.
3. Submit message by pressing Enter or clicking the Send button.
4. Verify transmission with screen capture to confirm the message bubble and checkmark appear.
